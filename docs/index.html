💰 РЕСУРСЫ

📊
Буфер (МБ) — разведданные. Заполни буфер кликами и пассивным доходом. Когда буфер полон — можно запускать FPV-штурм.
💵
Кредиты ($) — валюта для покупки улучшений. Зарабатывается от пассивного дохода, контрактов и мини-игр.

🖱️ ОСНОВНЫЕ ДЕЙСТВИЯ

👆
Клик по дрону — основной способ сбора данных. Каждый клик = +МБ в буфер. Бывают критические удары (x2 урон, зелёная вспышка).
⚡
Разгон — временный буст (x2.5 к пассиву на 8 секунд). Кнопка внизу экрана. Кулдаун 25 секунд.
🚀
FPV-Штурм — главная мини-игра. Доступна когда буфер заполнен на 100%. Поражение = потеря данных.

🚀 FPV-ШТУРМ (Мини-игра)

Мини-игра из 5 фаз:

1️⃣
Катапульта — нажмите ПРОБЕЛ когда маркер в зелёной зоне. Попадание в центр = «Идеальный запуск» (бонус).
2️⃣
Прорыв ПВО — жмите ПРОБЕЛ для подъёма дрона. Уклоняйтесь от стен, радарных лучей и ракет-перехватчиков. Собирайте 💠 данные.
3️⃣
Термальный захват — наведите мышь на корабль-цель и удерживайте прицел 2 секунды для захвата.
4️⃣
Взрыв — кинематическая сцена поражения цели.
5️⃣
Рейтинг S/A/B/C — оценка по скорости, точности и бонусам. S = x2 награды!
