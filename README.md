# Barracuda — Тактический Морской Дрон
Интерактивный 3D-симулятор управления морским дроном-разведчиком BARRACUDA.

## Особенности
- 🚢 3D-модель с оборудованием (ракеты, оптика, броня, водомёты, SATCOM)
- 🎮 FPV-миниигра штурма с 4 фазами
- 📡 Взлом РЭБ (сопоставление радиочастот)
- 🗺️ Карта секторов с уникальными миссиями
- 🏆 Система достижений
- 🌊 Кинематографический морской интерфейс

## Запуск
Откройте `web_preview/index.html` в браузере или:
```
python -m http.server 8080 --directory web_preview
```
