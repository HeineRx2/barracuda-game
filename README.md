## ⚓ Ключевые возможности v3.5.0

### 1. 📡 Радиоразведка и сбор телеметрии (SIGINT)
* Тапы по 3D-модели дрона производят сканирование эфира, перехват зашифрованных пакетов данных (**МБ**) и начисление оперативных средств (**$ кредиты**).
* Каждый клик заряжает боевую батарею **FPV-ШТУРМА**.
* **Полная мобильная адаптация**: Интерфейс полностью переработан для удобной игры на мобильных устройствах (Mobile-First UI).

### 2. 🌊 Подводная разведка, Сонар и Микро-ROV (Новое!)
* **3D-сонар бокового обзора (Side-Scan Sonar):** Водопадный дисплей эхолота (Waterfall Display), отрисовывающий рельеф дна, минные заграждения и затопленные кабели. Качество сканирования зависит от скорости хода.
* **Привязной микро-ROV и Магнитометр:** Спуск подводного аппарата на оптоволоконном кабеле для поиска подводных коммуникаций по градиенту магнитного поля ($nT$) и подключения «сифона данных».
* **Система динамического позиционирования (DPS Anchor):** Виртуальный якорь `[DPS HOLD]` для компенсации течения и удержания катера на точке во время диверсионных работ.

### 3. 🚁 Продвинутая авионика FPV-штурма (Новое!)
* **Соосный тяжелый VTOL (MK-4 COAXIAL):** Тяжелый штурмовой дрон с тандемной кумулятивной БЧ (+220% урона по броне фрегатов), не боящийся штормового ветра и качки при взлете.
* **Автономный терминальный AI-захват (Nvidia Jetson / NPU):** При подавлении видеоканала РЭБ (падение RSSI до 0%) нейросетевой модуль оптического потока автоматически захватывает и поражает выбранный узел цели (мостик/радар/машинное отделение).
* **PID-тюнинг полетного контроллера:** Тонкая настройка коэффициентов `P-Gain` (маневренность), `D-Gain` (демпфирование ветра) и `Expo` перед каждым вылетом.

### 4. 🚤 Гидродинамика и курсовая устойчивость (VSA) (Новое!)
* **Тумблер VSA `[STAB ON / OFF]`:** Возможность принудительно отключить стабилизацию и пустить катер в управляемый гидродинамический занос (дрифт на волнах) для резкого уклонения от прожекторов и зенитного огня.
* **Немагнитный корпус «Carbon-Stealth»:** 9.5-метровый цельнокарбоновый композит, обнуляющий магнитную сигнатуру ($0.0\,nT$) для безопасного прохождения над донными неконтактными минами.

### 5. 🏝️ Новая локация: «Кинбурнская коса / Днепровско-Бугский лиман»
* Мелководная карта с лабиринтом песчаных кос, переменной батиметрией (0.4 – 15 м) и патрулями береговой охраны.
* Индикатор глубин эхолота на HUD (`DEPTH: 1.2m`) с тревогой мелководья и риском кавитационной остановки водомета.

### 6. 🚢 Реальная классификация и бронирование флота врага
* От патрульных катеров «Раптор» (3,500 HP) и ракетных корветов «Буян-М» (45,000 HP) до фрегатов «Адмирал Эссен» (1,200,000 HP) и гвардейского флагмана «Москва» (6,000,000 HP, броня 75%).
* Различные зоны поражения: Мостик, Радар, Арт.Установка, с критическими бонусами к урону (x1.5 – x4.0).

### 7. 🗺️ Сюжетная кампания и тактические радиопереговоры (5 Секторов)
* **Сектор 1: Антоновский мост** — разведка Днепра и первые удары.
* **Сектор 2: Каховская ГЭС** — ночные операции в затопленных зонах.
* **Сектор 3: Херсонский порт** — перехват конвоев снабжения.
* **Сектор 4: Дельта Днепра** — ликвидация командного пункта в плавнях.
* **Сектор 5: Кинбурнская коса** — мелководный прорыв и подводные диверсии.

### 8. 🔊 Процедурное аудио (Web Audio API)
* Звуки гидроакустических пингов сонара (Chirp/Echo), подводных моторов ROV, щелчка тумблера VSA, гидро-дрифта и тревоги мелководья синтезируются в реальном времени.

## 🛠️ Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/HeineRx2/barracuda-game.git
cd barracuda-game

# Запуск локального сервера (разработка в web_preview)
python server.py
# Или
python -m http.server 8088 --directory docs
```
Откройте [http://localhost:8088](http://localhost:8088) в браузере.
