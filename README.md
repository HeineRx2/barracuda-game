# BARRACUDA GAME: Modernized Edition

Экшен-кликер про управление БПЛА, кибер-взлом, сбор разведданных и штурмы вражеских баз, переписанный на современной модульной архитектуре с использованием Vite и паттернов реактивного состояния.

## Особенности текущей версии

### 1. Архитектура 2.0 (ES6 + Proxy Store)
* Проект разбит на модули (`main.js`, `store.js`, `data.js`, `fpvMinigame.js`), что упрощает поддержку и расширение.
* **Централизованное хранилище (`store.js`)**: Все игровые данные управляются через `Proxy`, который автоматически сохраняет прогресс в `localStorage` и вызывает обновление UI при любых изменениях (без ручных вызовов `.saveGame()`).
* **Крипто-защита**: Сохранения игры зашифрованы с использованием алгоритма XOR + Base64, чтобы предотвратить банальный взлом через консоль браузера.

### 2. Хардкорная "Action-Based" Экономика
* **Упор на активную игру**: Пассивный доход значительно снижен (~90% от старых значений). Теперь для прокачки нужно вручную собирать данные, взламывать частоты РЭБ и участвовать в FPV-штурмах.
* **Экспоненциальный рост**: Цены на Аппаратное обеспечение, Кибер-софт, рецепты крафта и дроны растут экспоненциально, не позволяя пройти игру за час.
* **Ребаланс наград**: Награды за миссии, кибер-взломы и выполнение контрактов перенастроены для соответствия новым кривым цен.

### 3. Исправленный UI и FPV-движок
* HUD перенастроен: Подсказки и таймеры сдвинуты так, чтобы не перекрывать обзор в центре экрана.
* Ошибки `Illegal invocation` и проблемы с загрузкой старых форматов сохранений (Sets vs Arrays) полностью исправлены.
* Все компоненты 3D (Three.js), включая рендер воды, неба и дронов, перенесены в ассеты для корректной бандлинг-системы Vite.

## Стек технологий

* **Основа**: HTML5, Vanilla JavaScript (ES6 Modules), CSS3
* **3D Графика**: Three.js (Water, Sky, GLTFLoader)
* **Звук**: Web Audio API
* **Сборка и деплой**: Vite (для минификации и бандлинга в папку `/docs`)

## Развертывание и разработка

### Установка зависимостей
```bash
git clone https://github.com/HeineRx2/barracuda-game.git
cd barracuda-game
npm install
```

### Запуск локального сервера разработки
Используйте эту команду для тестирования игры в режиме реального времени с горячей перезагрузкой (Hot Module Replacement):
```bash
npm run dev
```
После запуска перейдите по адресу, который выдаст Vite (обычно `http://localhost:5173`).

### Сборка для Production
Игра компилируется напрямую в директорию `docs/`, что позволяет хостить её бесплатно на GitHub Pages.
```bash
npm run build
```
После сборки вы можете запустить `git commit` и `git push`, и GitHub Pages автоматически обновит игру для пользователей.
