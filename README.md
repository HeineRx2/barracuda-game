**BARRACUDA GAME** — это напряжённый экшен-кликер с элементами стратегии, посвящённый управлению современными БПЛА. Возьмите на себя роль оператора тактического дрона: собирайте разведданные, взламывайте системы связи, крафтите улучшения и проводите смертоносные FPV-штурмы вражеских кораблей!

---

## 🎮 Ключевые геймплейные механики

### 📡 Сбор SIGINT-данных (Кликер)
Основной источник заработка разведданных (МБ). Улучшайте аппаратное обеспечение (Антенны, Усилители, Базы данных), чтобы увеличить объем данных за клик и ёмкость серверов.

### ⚡ Кибер-Взлом (Мини-игра)
Подбирайте частоту и амплитуду сигналов РЭБ в напряженной мини-игре. Взлом нескольких каналов подряд приносит комбо-бонусы и сотни тысяч кредитов на ваш счет. Но будьте осторожны: вражеское противодействие попытается сбить вас со следа.

### 🚁 FPV-Штурм (3D Экшен)
Кульминация любой операции — запуск FPV-дрона. Маневрируйте между зенитными снарядами (CIWS), уклоняйтесь от ракет ПВО и нанесите разрушительный удар прямо в слабое место вражеского корабля. Используйте тепловизор (FLIR) для наведения противокорабельных ракет!

### 🔧 Инженерия и Крафт
Разблокируйте Чертежи за успешные штурмы, добывайте титан, чипы и нейро-блоки. Собирайте в Ангаре новые прототипы дронов с уникальными характеристиками скорости, маневренности и огневой мощи.

## 🛠️ Архитектура проекта 2.0

Игра была полностью переписана на современной модульной архитектуре с использованием сборщика Vite.

* **ES6 Модули**: Проект логически разделен на `main.js`, `store.js`, `data.js` и `fpvMinigame.js`.
* **Реактивный Store**: Все данные хранятся под защитой `Proxy`-объекта. Любое изменение (например, `store.state.creditsUSD += 100`) автоматически триггерит сохранение в LocalStorage и рендеринг UI-интерфейса!
* **Крипто-защита (XOR + Base64)**: Файлы сохранений защищены от банального редактирования через консоль браузера.
* **"Action-Based" Экономика**: Пассивный доход сведен к минимуму. Экспоненциальный рост стоимости улучшений заставит игрока активно использовать все игровые механики для достижения победы.

## 💻 Развертывание и разработка

### Стек технологий
* **Core**: HTML5, Vanilla JavaScript, CSS3
* **3D Движок**: Three.js (Water, Sky, GLTFLoader)
* **Звук**: Web Audio API (генерация звуковых волн, сонар)
* **Сборка**: Vite (для минификации и бандлинга в папку `/docs`)

### Инструкция по запуску
1. **Клонирование и установка**:
   ```bash
   git clone https://github.com/HeineRx2/barracuda-game.git
   cd barracuda-game
   npm install
   ```

2. **Запуск Dev-сервера**:
   Для тестирования игры в режиме реального времени с Hot Module Replacement (HMR):
   ```bash
   npm run dev
   ```

3. **Сборка для Production (GitHub Pages)**:
   Игра компилируется напрямую в директорию `docs/`.
   ```bash
   npm run build
   git commit -am "chore: build release"
   git push
   ```
