# 🌊 BARRACUDA // Автономный Ударный Морской Дрон v3.1.0

Тактический 3D-симулятор и инкрементальная стратегия боевого управления автономным морским ударным катером-дроном **«БАРРАКУДА»**.

🎮 **Играть онлайн**: [https://heinerx2.github.io/barracuda-game/](https://heinerx2.github.io/barracuda-game/)

---

## ⚓ Ключевые возможности

### 1. 📡 Радиоразведка и сбор телеметрии (SIGINT)
* Тапы по 3D-модели дрона производят сканирование эфира, перехват зашифрованных пакетов данных (**МБ**) и начисление оперативных средств (**$ кредиты**).
* Каждый клик заряжает боевую батарею **FPV-ШТУРМА**.

### 2. 🚀 FPV-Штурм и кинетический таран боевых кораблей
* Полноценная 4-фазная мини-игра:
  * **Фаза 1:** Форсажный взлёт и катапультирование.
  * **Фаза 2:** Скоростной прорыв через коридоры ПВО и радиопомех.
  * **Фаза 3:** Финальный захват цели и тепловое наведение.
  * **Фаза 4:** Кинетический удар с рейтинговой оценкой (S, A, B, C), уничтожением боевого корабля и сбором редких трофеев.

### 3. 🚢 Реальная классификация и бронирование флота врага
* От патрульных катеров «Раптор» (3,500 HP) и ракетных корветов «Буян-М» / «Каракурт» (45,000–100,000 HP) до фрегатов «Адмирал Эссен» (1,200,000 HP) и гвардейского флагмана «Москва» (6,000,000 HP, броня 75%).
* Корабли уничтожаются **только реальным вооружением** (FPV-штурм и ракетные залпы).

### 4. 🗺️ Сюжетная кампания и тактические радиопереговоры (4 Акта)
* **Акт I: Тень над Змеиным** — освобождение шельфа и уничтожение РЛС «Подсолнух».
* **Акт II: Прорыв бонов Севастополя** — форсирование защитных сетей бухты.
* **Акт III: Призрачный флот Новороссийска** — перехват танкеров снабжения.
* **Акт IV: Код «Левиафан»** — ликвидация супер-флагмана противника.
* Интерактивные радиодиалоги со штабом («Маяк») и офицерами РЭБ.

### 5. 🛠️ Ангар прототипов и Кузница трофеев
* **Прототипы:**
  * **BARRACUDA «PHANTOM»** (MK-1) — стелс-корпус, снижение плотности ПВО.
  * **BARRACUDA «STRIKE»** (MK-2) — тяжелый ракетоносец с x2.5 уроном FPV.
  * **BARRACUDA «AEGIS»** (MK-3) — комплекс РЭБ и постоянный рой ведомых дронов.
* **Кузница трофеев:** сборка бронеплит *«Титан-М»*, *Квантового дешифратора*, *Боеголовки X-9* и *Ведомого роя* из Черных ящиков, GaN-чипов и ИИ-ядер.

### 6. 📻 РЭБ & Спектральная дешифровка
* Мини-игра совмещения частот и амплитуд волн радиоэлектронной борьбы для дешифровки военных каналов.

### 7. 🧬 Дерево технологий НИОКР (13 узлов)
* 3 ветви развития: Стелс/РЭБ, Огневая мощь, Инженерия.

## 🛠️ Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/HeineRx2/barracuda-game.git
cd barracuda-game

# Запуск локального сервера
python server.py
# Или
python -m http.server 8088 --directory docs
```
Откройте [http://localhost:8088](http://localhost:8088) в браузере.
