# 🌊 BARRACUDA // Автономный Ударный Морской Дрон v3.2.0

Тактический 3D-симулятор и инкрементальная стратегия боевого управления автономным морским ударным катером-дроном **«БАРРАКУДА»**.

🎮 **Играть онлайн**: [https://heinerx2.github.io/barracuda-game/](https://heinerx2.github.io/barracuda-game/)

---

## ⚓ Ключевые возможности

### 1. 📡 Радиоразведка и сбор телеметрии (SIGINT)
* Тапы по 3D-модели дрона производят сканирование эфира, перехват зашифрованных пакетов данных (**МБ**) и начисление оперативных средств (**$ кредиты**).
* Каждый клик заряжает боевую батарею **FPV-ШТУРМА**.
* **Полная мобильная адаптация**: Интерфейс полностью переработан для удобной игры на мобильных устройствах (Mobile-First UI).

### 2. 🚁 Операции разведки и FPV-Штурм (Новое!)
* Полноценные кинетические FPV-миссии и аэроразведка.
* **Режим разведки**: Полёты над руслом Днепра (реалистичные камыши, плавучий мусор, марши) с поиском вражеских позиций с помощью 3D-маркеров и OSD-подсказок.
* **Зависание (Hover Mode)**: Возможность стабилизировать дрон в воздухе для фотофиксации и корректировки.
* **FPV-Удар**: Скоростной прорыв через коридоры ПВО, захват цели, тепловое наведение и ручная детонация.

### 3. 🚢 Реальная классификация и бронирование флота врага
* От патрульных катеров «Раптор» (3,500 HP) и ракетных корветов «Буян-М» (45,000 HP) до фрегатов «Адмирал Эссен» (1,200,000 HP) и гвардейского флагмана «Москва» (6,000,000 HP, броня 75%).
* Различные зоны поражения: Мостик, Радар, Арт.Установка, с критическими бонусами к урону (x1.5 – x2.5).

### 4. 🗺️ Сюжетная кампания и тактические радиопереговоры (4 Акта)
* **Акт I: Тень над Змеиным** — разведка Днепра и первые удары.
* **Акт II: Прорыв бонов Севастополя** — форсирование защитных сетей бухты.
* **Акт III: Призрачный флот Новороссийска** — перехват танкеров снабжения.
* **Акт IV: Код «Левиафан»** — ликвидация супер-флагмана противника.
* Интерактивные радиодиалоги со штабом («Маяк») и офицерами.

### 5. 🛠️ Ангар прототипов и Кузница трофеев
* **Прототипы:** «PHANTOM» (Стелс), «STRIKE» (Тяжёлый ракетоносец), «AEGIS» (РЭБ + Рой дронов).
* **Кузница трофеев:** Сборка бронеплит *«Титан-М»*, *Квантового дешифратора*, *Боеголовки X-9* и *Ведомого роя* из лута, собранного после миссий.

### 6. 🔊 Процедурное аудио (Web Audio API)
* Звуки двигателей, ветра, океана, форсажа и радиопереговоров генерируются процедурно в реальном времени, без использования тяжелых mp3 файлов, что дает невероятный реализм и погружение.

### 7. 🧬 Дерево технологий НИОКР
* 3 ветви развития (13 узлов): Стелс/РЭБ, Огневая мощь, Инженерия.

## 🛠️ Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/HeineRx2/barracuda-game.git
cd barracuda-game

# Запуск локального сервера (разработка в web_preview)
python server.py
# Или
python -m http.server 8088 --directory docs
```
Откройте [http://localhost:8088](http://localhost:8088) в браузере.
